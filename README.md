# 声线练习室

英语晨读打卡小工具（纯前端，无后端）。选句录音后按天留下练习记录（日期、时长、状态），同一天同一句自动合并，已掌握的句子重新练习会回到「练习中」。练习记录、掌握状态与筛选条件保存在浏览器本地，关掉再打开可接着看。

## 目录结构

- `src/data/phrases.ts` — 练习资料：句子库类型与初始数据
- `src/lib/practice.ts` — 记录判断：记录合并、状态流转、连续天数、本地持久化
- `src/App.tsx` — 页面展示：练习库、录音卡片、练习记录视图

## 运行

```bash
npm install
npm run dev      # 开发
npm run build    # 构建
```
