# 声线练习室 · 英语晨读打卡

纯前端英语晨读练习工具，替代纸质打卡表。选句录音后自动留下当天打卡记录（日期、时长、状态），关闭浏览器再打开记录仍在。

## 运行

```bash
npm install
npm run dev      # 开发预览
npm run build    # 类型检查并构建
```

## 功能

- **句子库**：按标签 / 待练 / 已掌握筛选，支持搜索与自定义添加句子。
- **录音打卡**：选句后开始录音，结束时保存当天记录（日期、时长、状态）。
  - 同一天同一句再次练习，只累加时长并刷新更新时间，不重复建记录。
  - 已掌握的句子重新练习后自动回到「练习中」。
- **练习记录**：侧边栏「练习记录」查看所有打卡，按更新时间倒序。
- **持久化**：练习记录、掌握状态、筛选与搜索条件均存于 localStorage，刷新 / 重开浏览器后接着看。

## 代码结构

```
src/
  data/phrases.ts   # 练习资料：句子类型与内置语料
  lib/practice.ts   # 记录判断：打卡记录的生成/合并规则、状态流转、localStorage 读写
  App.tsx           # 页面展示：句子库、录音卡片、练习记录视图
```

无新增第三方依赖。
